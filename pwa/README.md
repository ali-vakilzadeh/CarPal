# Consumer PWA (Web)

WP19: Next.js Progressive Web App for car owners and fleet drivers on the web, both desktop and mobile browsers. It complements the native app in `mobile/`.

Planned contents:
- **Public SEO pages (SSR):** provider and vendor profiles, showcases, Q&A.
- **Consumer web experience:** Discover, My Garage, Help Me (AI triage), appointments, community, profile and notification settings.
- **Driver issue reporting** for fleet drivers without the native app.
- PWA features: installable, web push, offline-tolerant shell, bundled fallback copy of the EN/FA UI dictionary.

The PWA also matters for markets where app-store distribution or native push is limited.
