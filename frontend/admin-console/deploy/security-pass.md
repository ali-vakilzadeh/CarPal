# Admin console security pass (AC11.T5, milestone M1)

Date: 2026-11-22. Scope: the console as deployed by this kit: Next.js 16.4.3, its BFF and `/id` proxy, the nginx
site, the systemd unit and `admin.env`. Method as in PWA P13: read the code paths, probe a production-mode build
(`CARPAL_ADMIN_ENV=prod`, strict, a throwaway client key) with curl, and run the pilot E2E suite against the strict
backend (`pnpm e2e:pilot`, `tests/e2e/pilot.spec.ts`). AC15 repeats this on the whole app.

**Result: no open high-severity finding.** One moderate finding is open (F-1, a framework update).

## Not covered

Firefox and Safari; real hardware keys and Windows Hello (Chrome's virtual authenticator only); a real server run of
the kit (`nginx -t`, certbot, systemd; no nginx on the development PC — `src/server/deploy-kit.test.ts` keeps the site
free of http-level directives the backend's site also sets, the cause of a duplicate-directive failure found in review);
load on the rate limits; the Redis session store (not used).

without a purpose, an unknown page, the moderator's disputes queue) and the dependencies; the pages outside the console
