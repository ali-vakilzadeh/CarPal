# Android App

Native Android host project generated by React Native. It will contain:
- Gradle build config, app ID, signing configs, and build flavors (dev / staging / prod)
- Firebase Cloud Messaging (push) setup
- Camera, photo library, and location permissions
- Native modules if needed later, e.g. Bluetooth OBDII pairing (Phase 2)
- Google Play release configuration

App logic is not written here. It lives in `../src`.
