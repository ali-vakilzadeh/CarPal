# iOS App

Native iOS host project generated by React Native. It will contain:
- Xcode project/workspace, CocoaPods, bundle ID, schemes (dev / staging / prod)
- APNs push notification entitlements
- Camera, photo library, and location usage descriptions (EN/FA)
- Native modules if needed later, e.g. Bluetooth OBDII pairing (Phase 2)
- App Store / TestFlight release configuration

App logic is not written here. It lives in `../src`.
